# ProxyHub

**A regularly updated collection of anonymous, working public proxies.**

ProxyHub automatically collects, checks, and publishes publicly available proxies.

## Supported protocols

ProxyHub supports the following proxy protocols:

- **HTTP** — standard HTTP proxies.
- **SOCKS4** — SOCKS version 4.
- **SOCKS5** — SOCKS version 5.

## Available data formats

Proxy lists are available in several formats to make integration with different tools and applications easier.

| Format | Description |
|---|---|
| **JSON** | Structured JSON containing proxy data. |
| **NSJSON** | Newline-delimited JSON (one JSON object per line). |
| **CSV** | Comma-separated values, suitable for spreadsheets and data processing. |
| **TXT** | Plain-text list using the `PROTOCOL://IP:PORT` format. |
| **HTTP** | Plain-text HTTP proxy list using the `IP:PORT` format. |
| **SOCKS4** | Plain-text SOCKS4 proxy list using the `IP:PORT` format. |
| **SOCKS5** | Plain-text SOCKS5 proxy list using the `IP:PORT` format. |
