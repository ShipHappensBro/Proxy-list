# 🌐 ProxyHub

**A regularly updated collection of publicly available proxies.**

ProxyHub automatically collects, checks, and publishes publicly available proxies every 15 minutes, providing country information for each proxy and offering proxy lists in multiple protocols and formats.

## 🔌 Supported protocols

ProxyHub supports four proxy protocols:

- **HTTP** — standard HTTP proxies.
- **SOCKS4** — SOCKS version 4.
- **SOCKS5** — SOCKS version 5.

## 📄 Available data formats

Proxy lists are available in multiple formats for easy integration with different tools, applications, and workflows.

| Format | Description |
|---|---|
| **JSON** | Structured JSON containing proxy data. |
| **NSJSON** | Newline-delimited JSON (one JSON object per line). |
| **CSV** | Comma-separated values, suitable for spreadsheets and data processing. |
| **TXT** | Plain-text list using the `PROTOCOL://IP:PORT` format. |
| **HTTP** | Plain-text HTTP proxy list using the `IP:PORT` format. |
| **SOCKS4** | Plain-text SOCKS4 proxy list using the `IP:PORT` format. |
| **SOCKS5** | Plain-text SOCKS5 proxy list using the `IP:PORT` format. |

## 🔄 Updates

ProxyHub automatically refreshes its proxy lists **every 15 minutes**, keeping the published data regularly updated.
